# BF++

## Синтаксис
- `>`, `<` - перемещение по памяти вправо/влево
- `+`, `-` - добавить/вычесть 1 текущей ячейки
- `[`, `]` - операторы цикла
- `.` - считать текущую ячейку и вернуть ASCII код в консоль
- `,` - считать символ из консоли и записать значение в текущую ячейку
- `}`, `{` - прыгнуть вправо/влево по коду на количество символов, соответствующее значению текущей ячейки
- `=` - добавить кол-во ячеек, соответствующее значению текущей ячейки

## Примеры

### Перемещение по памяти
```bfpp
>>>
```
Память:
```
      v
[ 0 0 0 0 0 0 ... 0 ]
```
### Добавление/вычитание
Добавляем
```bfpp
>+++++
```
Память:
```
    v
[ 0 5 0 0 0 0 ... 0 ]
```
Вычитаем
```bfpp
---
```
Память:
```
    v
[ 0 2 0 0 0 0 ... 0 ]
```
### Цикл
```bfpp
+++++[>++++++++<-]
```
Память:
```
[ 5  0 0 0 0 0 ... 0 ] <- до цикла
[ 4  8 0 0 0 0 ... 0 ] <- после 1 прохода
[ 3 16 0 0 0 0 ... 0 ] <- после 2 прохода
[ 2 24 0 0 0 0 ... 0 ] <- после 3 прохода
[ 1 32 0 0 0 0 ... 0 ] <- после 4 прохода
[ 0 40 0 0 0 0 ... 0 ] <- после 5 прохода
```
### Считать ячейку
Память:
```
      v
[ 0 0 65 0 0 0 ... 0 ]
```
```bfpp
.
```
Терминал:
```
A
```
### Пользовательский ввод
```bfpp
,+.
```
Вводим в терминал `A`
Терминал:
```
B
```
### Перемещение по коду (jmp)
Допустим мы хотим переместиться на пять команд вправо, это можно сделать так:
```bfpp
+++++}+++++++
```
Память будет выглядеть так:
```
[ 7 0 0 0 0 0 ... 0 ]
```
> Мы прибавили 5 к текущей ячейке и оператором `}` прыгнули на 5 команд вправо после которых идет только `++`
### Выделение памяти
В стандарте BF++ v1.0 при запуске программы доступна всего одна ячейка. Чтобы расширить память нужно использовать оператор `=`, который добавляет такое число ячеек справа, которое соответствует текущему значению ячейки

Начальная память:
```
[ 0 ]
```
Допустим, мы хотим добавить 7 ячеек, тогда нужно установить это значение в ячейку и применить `=`:
```bfpp
+++++++=
```
Теперь память выглядит так:
```bfpp
[ 7 0 0 0 0 0 0 0 ]
```
> Стоит помнить что оператор `=` не обнуляет ячейку и это необходимо делать вручную
